Descripción

Esta aplicación web representa la bandera de México y permite modificar la intensidad de sus colores verde y rojo mediante dos controles deslizantes. Cada control funciona como un potenciómetro digital.

Al modificar el potenciómetro verde, el programa calcula automáticamente los componentes RGB necesarios para conservar una tonalidad verde. De la misma manera, el potenciómetro rojo permite generar diferentes tonalidades de rojo.
